Projet de récupération et gestion d'emails - ACCK

Dans le cadre de mon stage au sein de l’entreprise ACCK, j’ai été chargé de développer une solution permettant d’automatiser la récupération et la gestion des emails reçus dans une boîte de messagerie spécifique. L’objectif principal était de faciliter l’intégration des échanges clients dans le système de gestion de tickets de l’entreprise. Le projet s'articule autour d'un script PHP capable de se connecter à une boîte mail via IMAP, IMAP signifie Internet Message Access Protocol (en français : protocole d'accès aux messages Internet).

C'est un protocole qui permet de lire et gérer les emails directement sur un serveur de messagerie sans les télécharger définitivement sur son ordinateur. d'extraire les informations utiles (expéditeur, date, sujet, corps du message, pièces jointes, etc.), et de les stocker de manière organisée dans une base de données MySQL.

Une interface web permet ensuite de visualiser ces emails et de consulter les détails associés, y compris les pièces jointes. Ce développement permet à l’entreprise de centraliser les échanges mails liés aux incidents, de fluidifier le travail des équipes support, et de poser les bases pour une future automatisation du traitement des tickets.

J’ai aussi mis en place un script pour filtrer certaines catégories techniques utilisées pour organiser les articles par langue, afin qu’elles ne s’affichent pas sur le site tout en restant utiles en interne.

Le code correspondant est présenté ci-dessous.

<?php
              function no_display_article_language_terms($terms, $post_id, $taxonomy) {
                  // Vérifier qu'on filtre bien les catégories (taxonomie "category")
                  if (!($taxonomy === 'category' && !empty($terms) && !is_wp_error($terms))) {
                      return $terms;
                  }
                  // Catégories à exclure
                  $excluded_slugs = ['articles-fr','articulos-es'];
              
                  // Filtrer les catégories pour ne pas afficher celles qui doivent être exclues
                  $filtered_terms = array_filter($terms, function ($term) use ($excluded_slugs) {
                      return !in_array($term->slug, $excluded_slugs);
                  });
              
                  return $filtered_terms;
              }
              
              // Appliquer le filtre sur les catégories affichées
              add_filter('get_the_terms', 'no_display_article_language_terms', 1, 3);
              ?>

Nancy Dominicains

Dans le cadre de l’optimisation de l’expérience utilisateur sur le site, j’ai également mis en place un script permettant de masquer automatiquement le formulaire de contact après son envoi. L’objectif était d’éviter toute confusion pour l’utilisateur en supprimant les champs une fois le message envoyé, tout en laissant visible le message de confirmation. Cette fonctionnalité a été appliquée à un formulaire spécifique, identifié par son ID, à l’aide de l’événement wpcf7mailsent de Contact Form 7.

En complément de cet aspect fonctionnel, j’ai également participé à la construction du visuel du site. Une base existait déjà, mais j’ai dû adapter et compléter cette structure en tenant compte de la charte graphique de l’entreprise et des besoins spécifiques du projet. Le système de fonctionnement et la technique reste la similaire au précèdent mais avec une utilisation de Trello pour la gestion des taches

Le code correspondant est présenté ci-dessous 

<?php
                  function cacher_formulaire_apres_envoi() {
                      ?>
                      <script>
                      document.addEventListener('wpcf7mailsent', function(event) {
                          if (event.detail.contactFormId == '119') { 
                              let form = document.querySelector('.wpcf7 form');
                              let response = document.querySelector('.wpcf7-response-output');
                              if (form) {
                                  let formFields = form.querySelectorAll('input, textarea, button, label'); 
                                  formFields.forEach(function(field) {
                                      field.style.display = 'none'; 
                                  });
                              }
                              if (response){
                                  response.style.display = 'block';
                              }
                          }
                      }, false);
                      </script>
                      <?php
                  }
                  add_action('wp_footer', 'cacher_formulaire_apres_envoi');
                  ?>
